# undigital-support

The support page and privacy policy for **Undigital**, a film emulation effect for Final Cut Pro
on the Mac. Served by GitHub Pages (once published).

- `index.html`: support page, getting started and FAQ, used as the App Store **Support URL**
- `privacy.html`: privacy policy, used as the App Store **Privacy Policy URL**
- `style.css`, `site.js`: from the Plimsoll support site, repainted in the icon's halation orange
- `mark.png`: the app icon at 216 × 216 (`sips` from `App/Assets.xcassets` in the app repo)

This repository is public only so GitHub Pages can serve it. It contains no application code;
the app lives in `~/Projects/undigital` (private).
